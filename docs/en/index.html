The DeepSeek Harness in your terminal

A terminal chat for the DeepSeek Harness: the conversation is the screen, the agent's tools fold into single lines, and what it asks to do you approve with a click.

Install on Linux or macOS — copy and paste into your terminal:
curl -fsSL https://auth-com-br.github.io/dsh-tui/install.sh | sh

Then open it with dsh-tui and choose a model with /models. No sudo: everything goes into your home folder.

What it does

The conversation is the screen

No boxes, no chrome: the transcript is anchored at the bottom, always in view, with the model and folder in a quiet footer.

Tools folded into lines

Each command the agent runs is one line: ⠋ Running while it runs, ✓ or ✗ when done, its output summed up below.

Approvals as a menu

When the agent wants to reach outside its workspace, the answers are listed: pick one with the arrows, Enter, a click, y or n.

Thinking that folds

The model's reasoning stays folded; a click or ctrl+t opens and closes it. esc interrupts an answer at any time.

Multi-line messages

ctrl+j breaks the line, as in Claude Code and OpenCode; Enter sends.

Copy, paste and images

A drag selects the conversation alone and copies it on release; ctrl+v attaches the clipboard's image; /copy copies the last answer.

Any model

/models sets up providers: an API key, or a server of your own, local or remote.

Your terminal's theme

Colors are derived from your terminal's background, light or dark, rather than fixed values.

Keys

ctrl + topen or fold the thinking
escinterrupt the answer; back to the latest
/helpevery key and command
ctrl + cquit

What the installer does

  1. Uses the Node.js 20+ you already have; if there is none, downloads the official build into ~/.local/share/dsh-tui/node, checked against its SHA-256 sum.
  2. Installs the DeepSeek Harness (dsh), at the version dsh-tui is tested on, into ~/.local.
  3. Downloads dsh-tui from this repository and wires the harness's tui profile to it.
  4. Puts the dsh-tui command in ~/.local/bin.

To update, run the same command again. Your settings, sessions and keys in ~/.dsh are left alone. The installer's code is docs/install.sh — read it before you run it, if you like.

To remove it: rm -rf ~/.local/share/dsh-tui ~/.local/bin/dsh-tui and npm uninstall -g --prefix ~/.local @deepseek-ai/dsh.
